# Working Branch Notes 取り扱い

- 詳細は `doc/guidelines/working-branch-notes-handling.md`
- 情報統制は `doc/guidelines/working-branch-notes-security.md` を必ず併読する。
- note は作業メモであり最終仕様書ではない。実装との 1:1 整合は要求しない。
- ファイル名は PR 採番前が `draft_<escaped-branch-name>.md`、採番後が `<PR-number>_<escaped-branch-name>.md`。
