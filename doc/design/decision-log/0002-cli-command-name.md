# 0002 CLI command name

- 状態: decided
- 作成日: 2026-08-18
- 最終更新日: 2026-08-18
- 関連: `doc/design/concept.md`

## 背景

新しい日時系 CLI を作るにあたり、インストール後に叩くコマンド名を決める必要がある。リポジトリ名とコマンド名を揃える想定である。

## 候補

- `bizdate`
- この時点では他の正式候補は挙げていない。

## 検討内容

`bizdate` は「業務日（business day）を扱う日付コマンド」という意図が短い英語で伝わる。公開前にざっと見た範囲では、同名コマンドの競合は目立たなかった。

コマンド名は後から変えると導入手順、help、配布物に広く効くため、実装前に固定しておく方が安い。

## 決定

CLI command name は `bizdate` とする。リポジトリ名もこれに合わせる。

## 理由

意図が短く伝わり、この時点で有力な代替案がなく、競合も目立たないため。

## 影響

- 利用者向け文書、CLI help、配布物のコマンド名は `bizdate` で統一する。
- パッケージ名や module path も、特段の理由がなければ `bizdate` に揃える。

## 後から見直す条件

- 同名の広く使われているコマンドやパッケージと衝突することが分かった場合。
- プロダクトの主目的が「業務日判定」から大きくずれた場合。
